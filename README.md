# STEPPE COFFEE — Review Generator

Mobile-first static website built with HTML, CSS and vanilla JavaScript.

## Deploy
This repository is ready for Vercel:
- Framework Preset: Other
- Build Command: leave empty
- Output Directory: `. ` (a single dot: `.`)
- Install Command: leave empty

The app is self-contained in `index.html`; no build step or backend is required.

## Features
- 1–5 star rating
- Order and experience selections
- Friendly, short and detailed writing styles
- Three locally generated review drafts
- Copy-to-clipboard buttons
- Responsive mobile layout

The generator only creates drafts from details selected or supplied by the visitor. It does not publish reviews or fabricate a visit. Reviewers should verify each draft reflects their real experience.
